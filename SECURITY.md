# Security

## Reporting a vulnerability

Please report security problems privately, through GitHub's
**"Report a vulnerability"** button on the Security tab of this repository.
Do not open a public issue or pull request for them.

Include what is affected, how to reproduce it, and what an attacker gains.
You will get an acknowledgement within a few days.

Fixes are released for the hosted service and for OpenClipnest at the same
time. Details of a vulnerability are published only after a fixed release has
been available long enough for self-hosted installs to upgrade.

## Supported versions

Only the latest release receives security fixes.
